# 三角洲护航小程序

  微信小程序 + Express 后端，为《三角洲行动》游戏玩家提供护航（陪玩/代练）服务。

  ## 功能

  - **护航下单**：选择大神/时长，填写区服、游戏ID，微信支付后自动派单
  - **趣味单**：特殊玩法，限购校验（每人/每周一次）
  - **大神系统**：排行榜、打手中心（接单/完成）、资料管理
  - **订单管理**：订单列表、状态追踪、取消退款
  - **钱包**：余额充值、提现

  ## 技术栈

  **前端（微信小程序）**
  - 原生小程序框架
  - 自定义主题切换（深色/浅色）
  - 本地 mock 数据兜底

  **后端（Express）**
  - SQLite 数据库（better-sqlite3）
  - JWT 登录（微信 code2Session）
  - 微信支付（待申请商户号）

  ## 运行

  ### 后端
  ```bash
  cd server
  npm install
  npm start
  # http://localhost:3000

  小程序

  1. 微信开发者工具导入项目根目录
  2. utils/config.js 配置 API_BASE（本地开发填 http://localhost:3000）
  3. 真机调试需勾选「局域网调试」
